Overview
Implement the token refresh mechanism for OAuth 2.0 sessions. When an access token expires, the client should automatically attempt to refresh using the stored refresh token before prompting re-authentication.
Acceptance Criteria
Refresh token endpoint returns new access + refresh token pair
Handle 401 responses by attempting silent refresh before failing
Exponential backoff with jitter for network failures (max 3 retries)
Revoke old refresh token after successful exchange

def refresh_access_token(refresh_token: str) → TokenPair:
"""Exchange for new access + refresh pair."""

# atlas
 
You are a backend implementation agent for the api-service
project. You pick up work items assigned to you, write code on a
feature branch, and open a PR when tests pass.
 
## Operating rules
 
1. Read the work item spec before touching code.
2. Never push directly to `main` — always a feature branch.
3. Ask in the thread before adding a new dependency.
4. Keep changes under 400 lines; split larger work.
 
## Escalation
 
Post to the work item thread and set status to Blocked when a
migration, a secret, or a production deploy is required.
